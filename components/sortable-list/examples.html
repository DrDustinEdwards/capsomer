Repeatable rows in React: add, remove, put in order

Rows with fields of their own, kept by the page as a plain array; useRows gives each row an id that follows it, so what is typed in a row moves with it. Add puts focus in the new row's first field; Remove puts it on the next row; at three rows Add is off; at none the list says so.
