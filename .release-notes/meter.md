# Meter and usage meter: one bar (breaking changes for an app on 0.1)

- `role="meter"` and the ARIA values moved from the `.cap-meter` root to the bar element, `.cap-meter-bar`, which is named by the label (`aria-labelledby`). The status word and the note stay outside the role so a screen reader reads them.
- `data-value` and `data-max` on the root are gone: the behaviour module reads `aria-valuenow`, `aria-valuemin` and `aria-valuemax` from the bar. New on the bar: `data-threshold` (a tick) and `data-projected` (a hatched projection with an end mark), both in the bar's unit.
- The bar is 8 px by default, with `data-size="sm"` (4 px) and `"lg"` (12 px). The track is a rounded pill with no border. The fill eases with a transform over 400 ms where motion is allowed.
- A tone's status word now sits beside the label (a `.cap-status` between the label and the value), not in the note. React: `warnAt`/`critAt` derive the tone and write the word; `words` sets it; a plain `tone` prop leaves the word to you (in `note`), as in 0.1. New props: `threshold`, `projected`, `size`, `measuring`, `className`, `as`, `after`. `tone` also accepts `"ok"`.
- No data is `data-tone="nodata"` with an `aria-hidden` bar and no role (as before, but the bar is now hidden from assistive technology). New: `data-state="indeterminate"` with `aria-busy="true"` for a value being measured.
- New exports from `capsomer/behaviour/meter`: `setBar`, `toneFor`, `update` (the old `setFill` is replaced by `setBar`; `ratio` and `enhance` stay).
- Usage meter: each row is now a `.cap-usage-item.cap-meter[data-cap="meter"]` built from the meter's parts. Removed classes: `.cap-usage-top`, `.cap-usage-name` (now `.cap-meter-label`), `.cap-usage-value` (now `.cap-meter-value`), `.cap-usage-bar` (now `.cap-meter-bar`), `.cap-usage-used` (now `.cap-meter-fill`), `.cap-usage-projected` (now the bar's `data-projected`). The `--used` and `--projected` custom properties are replaced by the meter's `--cap-meter-ratio` and `--cap-meter-projected` (0 to 1). Load `meter.css` with `usage-meter.css`. `assess`, `widths` and the React props are unchanged; `sizeBar` now draws through the meter.
- The usage meter's bar edge (a 1px `--line-strong` border) is gone; the limit is in the amount ("of 100,000").
