Dialog: a dialog whose form holds unsaved input (a control marked `data-cap-dirty` by field) no longer closes on a backdrop press or a swipe down; Esc, Close and Cancel still close it. Table: when the row holding focus is removed or hidden, focus moves to the next row, else the previous, else the table region, instead of dropping to the body. No token, class or HTML contract is removed or renamed.
