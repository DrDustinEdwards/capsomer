- **Breaking: web push classes are `cap-web-push-*`.** `.cap-push` collided with the layout utility `.cap-push` (`css/layout.css`, `margin-inline-start: auto`), which won. Renamed: `.cap-push` to `.cap-web-push`, and every part (`-note`, `-actions`, `-devices`, `-device`, `-device-name`, `-device-detail`, `-unsupported`) likewise. New part `.cap-web-push-live`, a status region mounted from the start that holds the note, so a note is read when it appears; a failure stays an alert beside it. Each Turn off names its device to a screen reader.
- **Breaking: `initialsOf` is gone from `capsomer/react/site-header` and `capsomer/behavior/site-header`.** Use `initials(name, email)` from `capsomer/behavior/avatar`, which now does what `initialsOf` did: the first and last word's first letters, two letters of a one-word name, else the email's first letter, else "?", upper case. The avatar's own initials change with it: a one-word name shows two letters, and lower-case names show upper case.
- **Breaking: `readPref` and `writePref` are gone from `capsomer/behavior/shell`.** Use `readStored` and `writeStored` from `capsomer/behavior/hooks`, which they wrapped. `syncServedTheme` now writes through `writeStored` too, so every reader of the key stays in step.
- **Breaking: the static stat tile's delta is Capsomer's `Delta`.** `delta` takes a node (`<Delta current previous higherIsBetter />`); `StatDelta`, `DeltaDirection` and `.cap-tile-delta` are removed (load `delta.css`). New: `--tile-align` (`start` by default; `center`, `end`) lines up a static tile's label, figure and note, and `figureFirst` puts the figure above the label. `StatTile`'s `chartTable` is now Enarratio's table markup (`dataTableBlock(table, label)`), and `chartTableLabel` is removed, so `capsomer/react/stat-tile` no longer imports Enarratio.
- **Breaking: `utcInputValue` and `fromUtcInputValue` are gone from `capsomer/behavior/time`.** Use `toDateTimeLocal(date)` and `fromDateTimeLocal(value)` from `capsomer/behavior/field` (UTC by default). `writing-progress` no longer re-exports `dayKey` and `knownZone` (import them from `capsomer/behavior/time`) and exports `weekdayOf`.
- **Breaking: `capsomer/token-check` keeps `stripCss`, `readDeclarations`, `resolveToken` and the raw-value checks (`tokenScale`, `rawValues`, `fixCss`).** Removed: `flattenMix`, `mediaBlock`, `firstValues`, `THEME_SELECTORS`, `readThemeBlocks`, `unresolved`, `verifyFallbacks`, `checkPairs`, `unmeasured`, `opacityDeclarations` and the `apca`/`contrast` re-export (no consumer imported them from here); it no longer needs `@drdustinedwards/site-helpers`. Fix: a selector matches a whole rule prelude, so `[data-theme="dark"]` no longer reads `[data-theme="dark"] .card`.
- **Removed tokens: `--z-dropdown` and `--z-drawer`**, which nothing read. The card's raised parts read `--z-raise`, the checklist run's bar `--z-sticky`, and the loading waves (dictionary entry, player) `--dur-wait`.
- **Removed: `useCommandHost` from `capsomer/react/command-menu`** (it is `capsomer/react/command-host`'s), and the `./behavior/graph` export entry, which `./behavior/*` already serves.
- **Removed: the second `.cap-clamp`** in `utilities.css`; `text.css` has it (`import "capsomer/text.css"`).
- **New: `FieldSet`** in `capsomer/react/field`: a fieldset with its legend, Required, help and error, the help and error read as its description. `DateInput` and schema form's choice and multi fields are built on it (the date parts no longer each carry the error in `aria-describedby`; the fieldset does, as GOV.UK's date input does).
- **Fixes.** Schema form: a date must be a real day (no February 31), and a controlled money field reports its changes. Search suggest: a failed suggest clears the last query's list. Step player: Enter or Space on Play pauses it. Sortable list: a board lane counts its own items for "N left" and `min`; the vanilla list keeps focus when its last item goes. Tabs: `guessPlatform` reads an iPhone as `ios` and Android as `android` (it said macos and linux), and web push names a device with it; the pill drag runs on `startPointerDrag` (Escape now cancels it). Site header: the theme key goes through the shortcuts registry (it skips typing in any text field, a modal and IME composition, and is listed in the shortcuts sheet); the stuck translucent ground reads `--header-translucent-mix` and `--header-blur`. Timeline and contents (toc): each React instance attaches only itself. Theme route: `themeAction` answers through site-runtime's `redirectResponse`, `private, no-store`. Admin-all loads `count.css`; catalog-all loads `link.css`. Links read `--prose-link-hover-ink` and `--prose-link-hover-decoration` wherever base.css loads. Roundtrip: a missing folder exits 2, and an edited block that does not parse back is a warning.
- **Changed look, small.** Source line, sources list and subscribe links use `AwayLink`: the link system's ↗ (the source line's own arrow goes) and "(opens another site)". Share row: the marks are the icon set's, and each name says it leaves the site. Settings row: the back chevron is the icon set's. Status mark: the icon set's check and cross. Contents: the current item's mark is a logical start edge (right in a right-to-left page). Scroll area, secret reveal and settings row draw the shared focus ring. Prose's print rules moved into `print.css`. Secret reveal's block no longer names itself (a `pre` takes no name; its section does), and subscribe links' heading id is generated unless `headingId` is given.
